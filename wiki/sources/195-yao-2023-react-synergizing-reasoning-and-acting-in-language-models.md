# Yao 等 - 2023 - ReAct Synergizing Reasoning and Acting in Language Models

## Metadata
- Source file: `raw/sources/2210.03629v3.pdf`
- Year: 2023
- Venue: ICLR 2023
- Pages: 33
- Ingest level: deep-ingest-v2 (ReAct method, benchmark setup, result direction, limitations, and ethics sections checked)

## Problem Framing
- The paper addresses a split in prior LLM work: chain-of-thought style reasoning was usually studied separately from action generation and environment interaction.
- The key problem is that pure reasoning can hallucinate or propagate errors, while action-only interaction lacks an explicit working memory for planning, search reformulation, and exception handling.
- The paper frames language reasoning traces as a controllable intermediate state that can guide external actions and interpret observations.

## Method
- Proposes ReAct, a prompting paradigm that interleaves natural-language thoughts, task-specific actions, and environment observations.
- In knowledge-intensive QA and fact verification, the action space uses a constrained Wikipedia API with search, lookup, and finish actions.
- In interactive decision-making tasks, sparse thoughts support goal decomposition, subgoal tracking, commonsense search over likely object locations, and choice of next action.
- The paper also studies hybrid strategies that back off between ReAct and self-consistent CoT when one mode is uncertain or fails to finish.

## Data and Evaluation Setup
- Knowledge-intensive reasoning tasks: HotpotQA and FEVER, evaluated in a question-only setting where the model must use internal knowledge or external Wikipedia interaction.
- Interactive decision-making tasks: ALFWorld and WebShop, where the model must navigate text environments or web-shopping interfaces through actions.
- Main experiments use PaLM-540B prompting; appendix experiments report GPT-3 `text-davinci-002` checks.
- Fine-tuning experiments bootstrap smaller PaLM models from trajectories generated by ReAct and other prompting baselines.

## Results and Claims
- ReAct improves over action-only prompting across the evaluated tasks, showing that reasoning traces help guide external actions.
- Compared with CoT, ReAct is more grounded by external observations but can suffer from reasoning-loop and search-result failures.
- Combining ReAct with CoT self-consistency is presented as a stronger strategy than using either mode alone for the knowledge-intensive tasks.
- Fine-tuning on ReAct-style trajectories is reported as promising for smaller models, especially because it teaches both reasoning and information-seeking behavior.

## Local Transfer
- The most reusable design pattern is not "always use long reasoning"; it is an explicit action loop with bounded observations and a stop condition.
- For the local IHC/SBIC relation-verifier idea, ReAct supports treating retrieval, context lookup, or community consultation as gated actions triggered by uncertainty or missing evidence.
- ReAct also gives a useful failure taxonomy for local verifier design: separate hallucinated reasoning, poor retrieval, repetitive action loops, and label ambiguity.
- The hybrid ReAct/CoT-SC strategy maps to confidence-based routing: use compact internal reasoning when it is stable, and external lookup only when internal agreement is weak.

## Limitations and Follow-ups
- In-context ReAct can require demonstrations that exceed practical context limits for large action spaces.
- Search quality is a bottleneck; non-informative observations can derail the reasoning trajectory.
- Action-space design controls safety and usefulness, so any local adaptation needs explicit allowed actions, step limits, and stop rules.
- The paper's experiments are broad LLM reasoning and interactive-decision benchmarks, not hate-speech or target-relation benchmarks.
