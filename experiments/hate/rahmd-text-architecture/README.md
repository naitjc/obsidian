# RA-HMD Text Architecture Exports

This folder keeps derived architecture diagrams for the text-only RA-HMD experiment line. It is experiment documentation, not raw source material or a server-runnable bundle.

## Variants

- `rahmd_text_architecture_v2_no_fusion.{svg,png}`: text-only design without the later fusion path.
- `rahmd_text_architecture_v3_target_assisted_retrieval.{svg,png}`: target-assisted retrieval design.

The SVG files are the editable versions; the PNG files are render exports. Keep each pair together. Durable method interpretation belongs in `wiki/concepts/rahmd-text-migration-lineage-2026-06-13.md` and `wiki/concepts/rahmd-inspired-ihc-relation-adaptation-2026-06-05.md`.
